# Comprehensive Threat Model & Security Controls

## 1. Overview
This threat model identifies potential attack vectors, unauthorized access attempts, insider threats, and evasive behaviors targeting examination paper confidentiality, integrity, and availability.

---

## 2. Threat Analysis Matrix

| Threat Category | Threat Description | Potential Impact | Existing Control | Detection Mechanism | System Limitation |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **T1: Pre-Release Paper Access Attempt** | Printing Staff or malicious insider attempts to view/print paper before scheduled exam time. | High - Early exposure of exam questions allows leak. | Time-Release Access Gatekeeper checks server time against `scheduled_release_time`. | Real-time audit event logging; Rule-based risk score +40; Security Alert generated. | Cannot prevent physical shoulder-surfing if screen is unshielded during legitimate printing. |
| **T2: Credential Compromise / Brute Force** | External attacker attempts password guessing on legitimate staff accounts. | High - Unauthorized account access leading to role impersonation. | Bcrypt password hashing; JWT token expiration (1 day); RBAC validation. | Burst audit log counter (>5 failed attempts in 5 mins triggers Alert); ML classification. | Weak passwords chosen by users if complexity policy is unenforced. |
| **T3: Insider Misuse (Moderator/Setter)** | Authenticated user attempts to modify or export paper outside authorized lifecycle stage. | Critical - Content tampering or illegitimate paper substitution. | Strict Paper State Machine validation; AES-256 encryption; SHA-256 checksums. | Audit log records all state transitions; content hash mismatch triggers alert. | Trusted insider with legitimate access during review window can read text on screen. |
| **T4: Evasive / Low-Rate Access Attacks** | Malicious user spreads out access attempts over long intervals to evade threshold rules. | High - Stealthy paper reconnaissance without triggering simple rate limits. | Feature engineering tracks `avg_request_interval_sec` and cumulative role risk. | Random Forest and Isolation Forest ML models trained on synthetic evasive datasets. | Machine learning models require periodic retraining on updated audit patterns. |
| **T5: Database / Storage Theft** | Adversary gains direct access to database files or raw storage volume. | Critical - Bulk extraction of all saved question papers. | AES-256 symmetric cipher encryption of all paper body text before insertion. | OS level storage access monitoring. | Encryption keys stored in environment variables must be protected via proper secret management. |
| **T6: Man-in-the-Middle (MitM) Interception** | Interception of network traffic between browser client and server API. | High - Eavesdropping on paper content during API transit. | Transport Layer Security (TLS/HTTPS) enforcement; JWT Bearer tokens. | TLS certificate validation. | Unencrypted HTTP local development environments are vulnerable if deployed insecurely. |

---

## 3. Fundamental Limitation & Research Scope Principle

> **Crucial Research Principle**:
> "Anomaly detection identifies deviations from observed behavioral patterns; it does **not** definitively establish that a paper leak actually occurred."
>
> All security alerts generated by SecureExam serve as **indicators for administrative investigation**, rather than automated proof of criminal paper leakage.
